Хранение данных (бд\кликхаус)

Варианты:
  - Базы данных - любая организованная коллекция данных (OLTP)
    - Реляционные (SQL, таблицы)
    - Нереляционные (NoSQL, не таблицы)
      - Гибкие, масштабируемые, разные типы, производительны на чтение и запись
  - Хранилища данных - больше данных, в основном для аналитики (OLAP) 
  - Озера данных - сборник любых источников данных 


OLTP:
1) Инициализация транзакции 
2) Обработка запроса 
3) Взаимодействие с БД 
4) Управление транзакциями 
5) Возврат результата 
6) Обновление состояния
(Atomicity, Consistency, Isolation, Durability) - принципы транзации 

Индексация - оптимизирует поиск \ чтение 
Индекс - сущность, которая является сопоставлением строк и идентификаторов (хеш таблицы, бинарные деревья)
1) Создание индекса 
2) Структура индекса 
3) Поиск данных 
4) Обновление индекса
