Хранение данных (бд\кликхаус)

Варианты:
  - Базы данных - любая организованная коллекция данных (OLTP)
    - Реляционные (SQL, таблицы)
    - Нереляционные (NoSQL, не таблицы)
      - Гибкие, масштабируемые, разные типы, производительны на чтение и запись
  - Хранилища данных - больше данных, в основном для аналитики (OLAP) 
    - Аналитика, отчетность, витрины данных (Redshift, BigQuery, Snowflake) 
    - Зачастую схема звезда или снежинка 
    - Хранят исторические данные 
  - Озера данных - сборник любых источников данных 


OLTP:
1) Инициализация транзакции 
2) Обработка запроса 
3) Взаимодействие с БД 
4) Управление транзакциями 
5) Возврат результата 
6) Обновление состояния
(Atomicity, Consistency, Isolation, Durability) - принципы транзации 

Индексация - оптимизирует поиск \ чтение 
Индекс - сущность, которая является сопоставлением строк и идентификаторов (хеш таблицы, бинарные деревья)
1) Создание индекса 
2) Структура индекса 
3) Поиск данных 
4) Обновление индекса

OLAP:
Online Analytical Processing - плохо с удалением и изменением, но все прекрасно с чтением.
Кубы данных - позволяют анализировать явления с множеством измерений. Структура. Оси - измерения. Ячейка - факт, измерение. Агрегация. 

Озера данных - хранилище (комплекс технологий), которое позволяет работать с любыми данными в любом количестве (структурированные или нет, сырые или нет, бинарные данные).
Масштабируемость, разнообразие, 

CLickhouse - колоночная субд, рзработанная для обработки больших объемов данных в режиме реального времени. Используется для аналитики 
1) Колоночное хранение данных 
2) Высокая производительность (тяжело положить запросами)
3) Масштабируемость горизонатльная  
4) Поддержка SQL 
5) Сжатие данных 
6) Поддержка различных форматов данных 
7) Интеграция с другими инструментами
  
  Хранение:
    - Таблицы
    - Схемы 
    - Индексы 
    - Partitions 
    - Сжатие 
    - Репликации 
    - Шардирование 

  Движки:
    - MergeTree 
    - ReplacingMergeTree 
    - SummingMergeTree 
    - AggregatingMergeTree 
    - CollapsingMergeTree/VersionedCollapsingMergeTree
    - TinyLog
    - Log 
    - Memory

  Полуагреггационные функции и State - возвращает не конкретное значение, а набор значений, по которым считается результат.
  sumState() - промежуточное состояние для суммы 
  sumMerge() - принимает состояние и возвращает окончательную сумму 
  constState(), avgState(), maxState()...

  Деплой: 
    - Ноды (зачастую несколько) 
    - Шарды
    - Репликации
